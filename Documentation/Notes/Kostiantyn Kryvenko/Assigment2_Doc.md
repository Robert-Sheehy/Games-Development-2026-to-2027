#Main Idea
For the creating of the script that showing a text I will firstly create a simple reusable C# script called "KK_TetxtScript" it will contain 2 functions one will be called "ShowText(string message)" which will be take a string argument
as a specific message that will be displayed and another one will be called "ClearText()"

#Main Components
  - Canvas: Called a "TextDisplay" and provide a UI for the text is displayed
  - TextMeshPro: Display and Control the text settings
  - Text display script: Allows message to be displayed and cleared
  - TextDisplayManager: An empty GameObject that holds the script

#Setup Instruction
  1. Add a TextMeshPro 
  2. Create an empty game object called TextDisplayManager
  3. Attach script to TextDisplayManager
  4. Attach the TextMeshPro to the Display Text field in the Inspector

#How to Use
  Call the ShowText() function and provide a message to display it on screen
  Call the ClearText() function to remove the text from the screen
